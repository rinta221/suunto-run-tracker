# Suunto ランニング記録アプリ 詳細設計書 ver.4.0
2026年6月 ／ 確定版

---

## 1. 背景と目的

### 1.1 解決する課題

Suuntoはスマートフォンアプリのみ対応しており、PC・タブレットでの練習データ俯瞰・分析が困難。現状の手作業をこのアプリで自動化する。

| 手順 | 現在の作業（手動） | 課題 | アプリで解決 |
|------|-------------------|------|------------|
| ① | Suuntoアプリでセッション確認 | スマホのみ、PC・タブレットで俯瞰できない | Suunto APIで自動取得・テーブル表示 |
| ② | 必要データをスプレッドシートに手動コピペ | 毎回手動転記。ミス・漏れのリスク | API連携で自動同期 |
| ③ | メニュー・感想等を手動入力 | 入力自体は継続（主要作業） | インライン編集で効率化 |
| ④ | データをコピペでChatGPTに貼り付け | 毎回コピペ。何を送るか選択が手間 | ボタン1つでAPI送信 |
| ⑤ | ChatGPTの返信をシートにコピペ | また手動コピペ。対応セルへの貼り付けが手間 | 返信を自動でセルに書き込み |

### 1.2 既存資産

- 既存スプレッドシート「トレーニングメニュー（12月〜）＋記録 ver.7」の列構成（A〜Z列）を完全再現
- スプレッドシートとの継続連携はTSVエクスポート機能で担保

## 2. システム概要

### 2.1 技術スタック（確定）

### 2.2 開発フェーズ

## 3. データ構造

### 3.1 アクティビティタイプ

すべての行は以下の3種類のいずれかに分類される。同一テーブルに混在し、行の色・アイコンで視覚的に区別する。

| タイプ | activity_type値 | 行の表示 | 説明 |
|--------|----------------|---------|------|
| ランニング | `running` | 白背景・🏃アイコン | Suunto連携データ（G〜X列に自動入力）または手動ランニング記録 |
| ランオフ | `rest` | 薄グレー背景・💤アイコン | 休養日の記録。Suuntoデータなし、メモ・感想のみ |
| 手動記録 | `manual` | 薄青背景・📝アイコン | 筋トレ・ストレッチ・クロストレーニング等。Suuntoデータなし |

### 3.2 メインテーブルのカラム構成

既存スプレッドシートのA〜Z列を完全再現し、新規列を追加。

| 列 | カラム名 | 種別 | 入力方法 | 備考 |
|----|---------|------|---------|------|
| — | activity_type | タイプ区分 | 自動/手動 | running / rest / manual。行の色・アイコン制御に使用 |
| A | date | 日付 | 手動/Suunto | YYYY-MM-DD |
| B | dow | 曜日 | 自動計算 | 月〜日 |
| C | menu | 練習メニュー | 手動 | サジェスト補完あり（過去履歴から） |
| D | メモ | 練習内容 | 手動 | フォーム意識・練習詳細。マルチライン対応 |
| E | locate | 場所 | 手動 | サジェスト補完あり（過去履歴から） |
| F | shoes | シューズ | 手動 | プルダウン（登録済みシューズから選択） |
| G | Distance | 距離（km） | Suunto自動 | runningのみ |
| H | Duration | タイム | Suunto自動 | HH:MM:SS |
| I | Pace | ペース | Suunto自動 | MM:SS/km |
| J | avg. HR | 平均心拍 | Suunto自動 | 最大心拍比率（%） |
| K | Elev. | 累積標高（m） | Suunto自動 | |
| L | CS | Cadence Score | Suunto自動 | **メインテーブルには表示しない**（詳細パネルのみ） |
| M | Energy | 消費kcal | Suunto自動 | |
| N | Splits | ラップデータ | Suunto自動 | **DBに保存しない**。AI評価時にSuunto APIからその場で取得 |
| O | Title | 活動タイトル | Suunto自動 | Suuntoアプリ上のアクティビティ名 |
| P | TRIMP | 負荷指数 | Suunto自動 | Training Impulse（強度×時間） |
| Q | VO2max | VO2max推定値 | Suunto自動 | Suunto算出推定値 |
| R | Ground contact | 接地時間（ms） | Suunto自動 | |
| S | GCB | 接地左右バランス | Suunto自動 | 左右%（例：50.5% - 49.5%） |
| T | cal oscillation | 上下動（cm） | Suunto自動 | |
| U | 最大歩幅ケイデンス | 最大ケイデンス（spm） | Suunto自動 | |
| V | 平均歩幅ケイデンス | 平均ケイデンス（spm） | Suunto自動 | |
| W | 平均歩幅 | ストライド長（cm） | Suunto自動 | |
| X | 左右接地バランス | 左右バランス | Suunto自動 | 例：50.5% - 49.5% |
| Y | 感想 | 主観的感想 | 手動 | ★AI送信の必須項目 |
| 追加 | planned_menu | 予定メニュー | AI生成（承認時に自動セット） | AIが提案し承認されたメニュー。実績と乖離した場合の振り返り用。上書き不可 |
| 追加 | menu | 実績メニュー | 手動入力 | 実際に行ったメニュー。AI提案行は承認後に手動で上書き |
| 追加 | claude_eval | 客観評価 | Claude API自動 | データドリブンな客観的分析・指摘 |
| 追加 | gpt_eval | コーチングコメント | ChatGPT API自動 | 感情的サポート・継続を後押しするコーチング |
| 追加 | phase_id | 練習フェーズID | 自動（フェーズ設定から） | phasesテーブルへの外部キー |

### 3.3 SQLiteスキーマ

#### sessionsテーブル

```sql
CREATE TABLE sessions (
  id                      TEXT PRIMARY KEY,       -- UUID
  activity_type           TEXT NOT NULL,          -- 'running' / 'rest' / 'manual'
  source                  TEXT DEFAULT 'manual',  -- 'manual' / 'suunto' / 'ai_generated'
  suunto_workout_id       TEXT,                   -- Phase 3で付与
  phase_id                TEXT,                   -- FK -> phases.id
  date                    TEXT NOT NULL,          -- YYYY-MM-DD
  planned_menu            TEXT,                   -- AI提案メニュー（承認時にセット・上書き不可）
  menu                    TEXT,                   -- 実績メニュー（手動入力・AI提案行は上書き可）
  memo                    TEXT,                   -- D列（手動）
  locate                  TEXT,                   -- E列（手動）
  shoes                   TEXT,                   -- F列（手動）
  distance_km             REAL,                   -- G列
  duration_s              INTEGER,                -- H列（秒）
  pace_per_km_s           INTEGER,                -- I列（秒/km）
  avg_hr_pct              REAL,                   -- J列（%）
  elevation_m             REAL,                   -- K列
  cadence_score           REAL,                   -- L列
  energy_kcal             INTEGER,                -- M列
  title                   TEXT,                   -- O列
  trimp                   REAL,                   -- P列
  vo2max                  REAL,                   -- Q列
  ground_contact_ms       REAL,                   -- R列
  gcb_left_pct            REAL,                   -- S列
  vertical_oscillation_cm REAL,                   -- T列
  cadence_max_spm         REAL,                   -- U列
  cadence_avg_spm         REAL,                   -- V列
  stride_length_cm        REAL,                   -- W列
  gc_balance              TEXT,                   -- X列（例："50.5% - 49.5%"）
  impression              TEXT,                   -- Y列（手動）★AI送信必須
  claude_eval             TEXT,                   -- Claude客観評価
  claude_eval_at          TEXT,                   -- Claude評価取得日時
  gpt_eval                TEXT,                   -- GPTコーチングコメント
  gpt_eval_at             TEXT,                   -- GPT評価取得日時
  created_at              TEXT NOT NULL,
  updated_at              TEXT NOT NULL
);
```

#### phasesテーブル（練習フェーズ管理）

```sql
CREATE TABLE phases (
  id          TEXT PRIMARY KEY,  -- UUID
  name        TEXT NOT NULL,     -- 例：基礎期・ビルドアップ期・レース前・回復期
  start_date  TEXT NOT NULL,     -- YYYY-MM-DD
  end_date    TEXT,              -- NULL = 現在進行中
  color       TEXT,              -- バッジ色（例：#3B82F6）
  notes       TEXT,              -- フェーズの目標・方針メモ
  created_at  TEXT NOT NULL
);
```

> ※ sessionsのphase_idは、セッションのdateがphasesのstart_date〜end_dateに含まれる場合に自動付与。手動での上書きも可能。

#### shoesテーブル

```sql
CREATE TABLE shoes (
  id            TEXT PRIMARY KEY,  -- UUID
  name          TEXT NOT NULL,     -- 例：neo zen / superblast2 / speed4 / WR28
  purchase_date TEXT,
  total_km      REAL,              -- sessionsから自動集計
  is_active     INTEGER DEFAULT 1, -- 1=現役 / 0=引退
  notes         TEXT
);
```

## 4. 表示・ナビゲーション仕様

### 4.1 月単位表示

| 項目 | 仕様 |
|------|------|
| 表示単位 | 1ヶ月分（1日〜末日） |
| 起動時のデフォルト月 | 最新データが存在する月を自動表示 |
| 月切り替えUI | ← 前月 ／ 年月表示（クリックでカレンダーピッカー）／ 次月 → |
| 1日複数行 | WU・メイン・CL等の複数セッションはそれぞれ別行で表示 |
| ランオフ行 | 表示する（activity_type='rest'として記録・表示） |
| データ取得範囲 | Suuntoに登録されている全期間・全データ（初回同期時に全件取得） |
| 差分同期 | 2回目以降は最終同期日時以降の新規セッションのみ取得 |

### 4.2 ソート仕様

| 項目 | 仕様 |
|------|------|
| デフォルトソート | 日付の昇順（古い→新しい） |
| ソート変更 | 各列のヘッダーをクリックで昇順/降順切り替え |
| ソート対象列 | date / distance / pace / avg_hr / trimp / vo2max 等の数値・日付列 |
| 複合ソート | Phase 1では単一列ソートのみ。複合ソートは将来対応 |

### 4.3 絞り込み仕様

| 絞り込み条件 | Phase | 仕様 |
|------------|-------|------|
| 月選択（ナビゲーション） | 1 | メイン操作。月単位でデータを切り替え |
| アクティビティタイプ | 1 | running / rest / manual のON/OFFトグル |
| フリーテキスト検索 | 1 | menu・メモ・感想・AI評価を横断検索 |
| シューズ | 2以降 | 特定シューズのみ表示（シューズ別分析用） |
| 距離範囲 | 2以降 | 例：10km以上のみ表示 |
| 練習フェーズ | 2以降 | 特定フェーズのみ表示（フェーズ別分析用） |

> ※ 絞り込み条件の詳細仕様はユーザーのイメージが固まった段階で設計する。

### 4.4 フェーズサマリー

| 項目 | 仕様 |
|------|------|
| 表示トリガー | フェーズのstart_date / end_dateがある月に自動表示 |
| サマリー表示内容 | フェーズ名 / 期間（開始〜終了日）/ 総距離 / 練習回数 / 平均TRIMP / 合計TRIMP |
| 表示位置 | フェーズ終了日の行の直下にサマリーバー行を挿入 |
| 現在進行フェーズ | end_dateが未設定の場合、当月末日時点でのサマリーを表示（随時更新） |
| 複数フェーズ | 1ヶ月に複数フェーズが存在する場合はそれぞれサマリーバーを表示 |

## 5. AI評価機能（コア機能）

### 5.1 AI役割分担

| 列 | AI | キャラクター | プロンプト設計の方向性 |
|----|-----|------------|----------------------|
| claude_eval | Claude（Anthropic） | 客観コーチ | データの事実を指摘。数字が示す改善点を明確に。感情的配慮より正確さを優先 |
| gpt_eval | ChatGPT（OpenAI） | 寄り添いコーチ | 感情を受け止め、ポジティブに次へ向かわせる。継続意欲を高めるトーン |

### 5.2 送信データ仕様

#### セッションサマリー（毎回送信）

| 送信フィールド | 元カラム | 備考 |
|-------------|---------|------|
| date | A | 時系列での文脈把握 |
| menu | C | 練習の意図・目的を理解させる |
| memo | D | フォーム意識・練習内容の詳細 |
| distance_km | G | 運動量 |
| duration | H | 運動時間 |
| pace | I | 強度指標 |
| avg_hr_pct | J | 心拍強度（負荷の客観指標） |
| elevation_m | K | コースの起伏（ペース解釈に影響） |
| trimp | P | トレーニング負荷の定量値 |
| vo2max | Q | 体力状態の推移 |
| ground_contact_ms | R | フォーム効率の客観指標 |
| gcb_left_pct | S | 左右バランスの偏り検出 |
| vertical_oscillation_cm | T | 上下無駄動きの検出 |
| cadence_avg_spm | V | ストライド効率 |
| stride_length_cm | W | ストライド長の評価 |
| **impression（感想）** | **Y** | **★必須。ランナーの主観。AIの評価の出発点** |

#### Lapデータ（全ラップ添付）

- **DBには保存しない**。AI評価ボタン押下時にSuunto APIからその場で取得して添付
- Phase 1/2ではセッションに紐づくダミーJSONで代替
- 送信フィールド：`lap_number / pace / avg_hr / power / cadence / stride_length / ground_contact / vertical_oscillation`

> ※ 長距離（フルマラソン等40ラップ超）ではトークン消費大。将来的に「全ラップ/5kmサマリー」選択オプションを追加予定。

### 5.3 システムプロンプト（初期値・設定画面でカスタマイズ可）

#### Claude用（客観評価）

```
あなたはランニングの専門コーチです。提供されたセッションデータとラップデータ、
およびランナー本人の感想を分析し、以下の観点で200〜300字でコメントしてください：
①客観データと主観（感想）の一致・乖離
②フォーム効率の評価（接地時間・上下動・左右バランス）
③数字に基づいた具体的な改善点
褒めることより正確な分析を優先してください。
```

#### ChatGPT用（寄り添いコーチング）

```
あなたは親しみやすいランニングコーチです。セッションデータとランナーの感想をもとに、
200〜300字で励ましのコメントを書いてください：
①今日の走りで良かった点を具体的に引き出す
②ランナーの感想に共感し、気持ちに寄り添う
③次回のトレーニングへのポジティブな提案
継続意欲を高めるトーンを心がけてください。
```

### 5.4 UIフロー

- 各行末尾に「Claude」「GPT」ボタンを配置
- ボタン押下 → 該当セル（claude_eval / gpt_eval）にローディングスピナー表示
- API返信受信 → セルに自動書き込み・SQLiteに保存（`claude_eval_at` / `gpt_eval_at` も更新）
- 失敗時 → エラーメッセージをセル内に表示（リトライボタン付き）
- 複数行チェックボックス選択 → ツールバーの「一括評価」ボタンで複数セッションをまとめて評価

## 6. エクスポート機能

### 6.1 TSVエクスポート（スプレッドシート連携）

- 既存スプレッドシートの列構成と互換のTSVを出力
- GoogleスプレッドシートやExcelにそのままペースト可能
- 文字コード：UTF-8 with BOM（Excel文字化け防止）
- 出力範囲：全件 / 表示中の月 / 選択行

### 6.2 Markdownエクスポート（AI共有用）

- 選択セッションをMarkdownテーブル＋テキスト形式で出力
- Lapデータ込みの詳細版とサマリーのみの簡易版を選択可能
- 冒頭にプロンプト文を自動付加（「練習メニューを提案して」「パフォーマンスのトレンドを分析して」等）
- クリップボードコピーボタンでワンクリック → Claude.ai / ChatGPTに貼り付け
- フェーズサマリーも含めてエクスポート可能

## 7. 画面設計

### 7.1 メイン画面（セッション一覧）

#### レイアウト構成

- **ヘッダー（固定）**：アプリ名 / Suunto同期ボタン＆最終同期日時 / 設定アイコン
- **月ナビゲーション**：← 前月 ／ 2025年12月（クリックでカレンダーピッカー）／ 次月 →
- **フィルターバー**：アクティビティタイプトグル（🏃 / 💤 / 📝）＋フリーテキスト検索
- **ツールバー**：全選択チェックボックス / 一括Claude評価 / 一括GPT評価 / エクスポート
- **テーブル本体**：全列・横スクロール・date＆menu列固定
- **フェーズサマリーバー**：フェーズ終了行の直下に自動挿入（背景色付き帯）
- **ステータスバー（固定）**：表示件数 / 選択件数 / 月間合計距離 / 月間合計TRIMP

#### 列グループとデフォルト表示

| グループ | 対象列 | デフォルト | 切替 |
|---------|-------|----------|------|
| 基本情報 | activity_type / A（date）/ B（dow）/ C（menu）/ D（メモ）/ E（locate）/ F（shoes） | 表示 | 非表示不可 |
| パフォーマンス | G（距離）/ H（タイム）/ I（ペース）/ J（HR）/ K（標高）/ M（kcal） | 表示 | 設定で非表示可 |
| 負荷指標 | P（TRIMP）/ Q（VO2max） | 表示 | 設定で非表示可 |
| バイオメカニクス（セッション平均） | R（GC ms）/ T（VO cm）/ W（Stride cm）/ S（GCB %） | **表示**（常時） | 非表示不可 |
| 予定・実績 | planned_menu（予定）/ menu（実績） | 表示 | 非表示不可（AI生成行のみplanned_menu表示） |
| AI評価・感想 | Y（感想）/ claude_eval / gpt_eval | 表示 | 非表示不可 |

#### 行の視覚的区別

| 行の種類 | アイコン | 背景色 | 説明 |
|---------|---------|-------|------|
| ランニング | 🏃 | 白（#FFFFFF） | 通常の練習行 |
| ランオフ | 💤 | 薄グレー（#F3F4F6） | 休養日。Suuntoデータなし |
| 手動記録 | 📝 | 薄青（#EFF6FF） | 筋トレ・ストレッチ等 |
| フェーズサマリー | 📊 | フェーズ色（薄め） | フェーズ終了時に自動挿入される集計行 |

### 7.2 セッション詳細パネル

- 右スライドイン（幅380px）。テーブルを隠さず閲覧継続可能
- サマリーカード：距離・ペース・HR・TRIMP・VO2maxを大きく表示
- Lapテーブル：全ラップデータ一覧（Lapシート相当）
- グラフ：ラップ別ペース推移・HR推移・パワー推移（Chart.js）
- バイオメカニクスグラフ：接地時間・上下動・GCBのラップ推移
- AI評価：claude_eval / gpt_eval を並列表示。各「再評価」ボタン付き

## 10. データソース仕様（実装メモ）

### データ取得方針

- **実装日以降**：Suunto API連携で自動取得（Phase 3）
- **過去データ**：設定画面の「過去データ取得」ボタンで期間指定してバックグラウンド取得（Runalyzeのhistory import toolと同様）
- **既存スプレッドシートデータ**：menu・メモ・感想・シューズ等の手動列のみ、日付をキーに後からマージ可能な設計

### エクスポート形式の比較と採用決定

Suuntoアプリからエクスポートできる形式：GPXワークアウト / GPXルート / KMLルート / FITファイル / **JSON ← 採用**

| 形式 | ラップVO/GCT/Stride/GCB | 採用 |
|---|---|---|
| FIT | ❌ セッションサマリーのみ | ✗ |
| JSON | ✅ ラップレベルで全バイオメカニクスあり | ✅ |

→ **JSONを正式なデータソースとして採用する**

### JSONデータの変換仕様

#### セッションサマリー（Header）

| JSONフィールド | 変換 | DBフィールド |
|---|---|---|
| Distance | ÷ 1000 = km | distance_km |
| Duration | 秒そのまま | duration_s |
| Ascent | m単位 | elevation_m |
| Energy | ÷ 4184 = kcal（J→kcal） | energy_kcal |
| MAXVO2 | そのまま | vo2max |
| EPOC | そのまま（TRIMP相当） | trimp |
| GroundContactTime.Avg | × 1000 = ms | ground_contact_ms |
| LeftGroundContactBalance.Avg | %そのまま | gcb_left_pct |
| VerticalOscillation.Avg | × 100 = cm | vertical_oscillation_cm |
| Stride.Avg | × 100 = cm | stride_length_cm |

#### ラップデータ（Windows配列）

| JSONフィールド | 変換 | ラップフィールド |
|---|---|---|
| VerticalOscillation[0].Avg | × 100 = cm | vertical_oscillation_cm ✅ |
| GroundContactTime[0].Avg | × 1000 = ms | ground_contact_ms ✅ |
| Stride[0].Avg | m単位そのまま | stride_length_m ✅ |
| LeftGroundContactBalance[0].Avg | %そのまま | gcb_left_pct ✅ |
| Power[0].Avg | Wそのまま | power_w ✅ |
| Speed[0].Avg | m/s（pace変換） | pace_s ✅ |

## 11. AI練習メニュー生成機能（Phase 2.5）

### 概要

現在の運用（ChatGPTにデータをコピペ → TSV返答をスプレッドシートに貼り付け）をアプリ内で完結させる。

### UIフロー

1. ツールバーに「📅 メニュー生成」ボタンを追加
2. モーダルで以下を設定：
   - **参照期間**：AIに渡す過去データの範囲（例：5/1〜5/31）
   - **生成期間**：メニューを作成する期間（例：6/1〜6/30）
   - **目標・フェーズ**：フリーテキスト（例：「フルマラソン強化期。サブ3.5を目標」）
   - **AI選択**：Claude / ChatGPT
3. 送信 → AIがTSV形式で返答
4. プレビューモーダルで1行ずつ確認・編集可能
5. 承認 → DBに一括登録

### AIへの送信データ

```json
{
  "request": "以下の練習記録を参考に、{生成期間}の練習メニューを提案してください。返答はTSV形式で返してください。",
  "target_period": "2026-06-01 〜 2026-06-30",
  "goal": "フルマラソン強化期。サブ3.5を目標。",
  "phase": "ビルドアップ期",
  "output_format": "TSV（列順：date/dow/menu/メモ/locate/shoes）date列はM/D形式、dow列は漢字1文字",
  "reference_sessions": [ ...参照期間の全セッション（laps含む）... ]
}
```

### AIからの返答形式（TSV）

既存スプレッドシートと同じ形式で返答させる：

```
5/18	月	ランオフ	【完全回復】足裏・脚全体の確認。走らない。	-	-
5/19	火	ランオフ or 20〜30分散歩	【回復継続】朝一の足裏・膝を確認。	近所	speed5
5/22	金	朝2〜3km 接地確認	【接地保存】真下接地と足離れを確認。	砧公園	Novablast5
```

### DBへの取り込み仕様

| TSV列 | DBフィールド | 備考 |
|-------|------------|------|
| date（M/D形式） | date | 生成期間の年を補完 |
| dow | — | 表示のみ、保存不要 |
| menu | planned_menu | AI提案内容として保存（上書き不可） |
| menu | menu | 同値で初期セット。実績入力時に上書きされる |
| メモ | memo | そのまま |
| locate | locate | `-`は空文字に変換 |
| shoes | shoes | `-`は空文字に変換 |
| — | activity_type | menuに「ランオフ」含む→rest、距離記載あり→running、それ以外→manual |
| — | source | `"ai_generated"`（AI生成フラグ） |

### プレビューモーダルの仕様

- TSV返答をパースしてテーブル形式でプレビュー表示
- 各行をインライン編集可能（menu・メモ・locate・shoes）
- 不要な行はチェックボックスで除外可能
- 「全件承認」または「選択行のみ登録」ボタン
- 登録済みデータとの重複チェック（同日付のデータがある場合は警告）

### 予定と実績の差分をAIに送る仕様

次回メニュー生成時、参照期間にAI生成行が含まれる場合は予定・実績・理由をセットで送信する：

```json
{
  "sessions": [
    {
      "date": "2026-06-01",
      "planned_menu": "インターバル 1km×5",
      "actual_menu": "ランオフ",
      "memo": "膝痛のため中止",
      "distance_km": null
    },
    {
      "date": "2026-06-02",
      "planned_menu": "LSD 20km",
      "actual_menu": "LSD 20km",
      "memo": "予定通り実施",
      "distance_km": 20.1
    }
  ]
}
```

AIはこの差分から「予定が飛んだ理由・回数・パターン」を読み取り、次の提案に反映できる。

### システムプロンプト

#### Claude用

```
あなたはランニングコーチです。提供された練習記録データを分析し、
{生成期間}の練習メニューを提案してください。

制約：
- 返答はTSV形式のみ（ヘッダー行なし、説明文不要）
- 列順：date(M/D形式) / dow(漢字1文字) / menu / メモ / locate / shoes
- メモは【】でカテゴリを示し、具体的な指示を記載する
- shoesは記録から推測して適切なものを選ぶ
- locateは過去の記録から適切な場所を選ぶ
- ランオフ日も必ず含める
```

#### ChatGPT用

```
あなたはランニングトレーナーです。提供された練習記録を参考に、
{生成期間}の練習メニューをTSV形式で提案してください。

出力形式（ヘッダー・説明文不要、TSVのみ）：
date(M/D) [TAB] dow(漢字1文字) [TAB] menu [TAB] メモ [TAB] locate [TAB] shoes
```
